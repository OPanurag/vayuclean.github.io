# VayuClean React Website

Welcome to the VayuClean website project! This is a modern React web application, styled with Tailwind CSS, and organized for easy development and maintenance. This guide will help anyone—regardless of technical background—understand the project structure and how to use it.

## 🗂️ What Does Each File/Folder Do?

### Top-Level Files
- **README.md**: This file! Explains everything.
- **package.json**: Lists all the tools and libraries your project uses. Also defines commands you can run (see below).
- **package-lock.json**: Keeps track of exactly which versions of libraries are installed.
- **.gitignore**: Tells Git which files/folders to ignore (so you don’t accidentally upload them).

### Main Folders
- **public/**: Contains files that are served directly to the browser. You rarely need to edit these except for `index.html` (the main HTML template).
- **src/**: The heart of your website! All your code, components, and pages live here.
  - **App.js**: The main React component. Controls what’s shown on the homepage.
  - **App.css**: Styles for the App component.
  - **index.js**: The entry point for your React app. Loads everything.
  - **index.css**: Main CSS file. Tailwind CSS is set up here.
  - **logo.svg**: Logo image.
  - **reportWebVitals.js**: Optional file for measuring performance.
  - **setupTests.js**: Optional file for running tests.
  - **components/**: Contains reusable pieces of your site (like Navbar, Footer, Hero).
  - **pages/**: Contains the main pages of your site (Home, About, Contact, Products, Team).
    - **productDetails/**: Contains detail pages for individual products (AHU, PassBox).
- **dist/**: Contains the final, processed CSS file generated by Tailwind. You don’t edit this directly.
- **node_modules/**: All the code libraries your project uses. Managed automatically—never edit this!

### Configuration Files
- **tailwind.config.js**: Tells Tailwind CSS which files to scan for classes. You can customize Tailwind here.
- **postcss.config.js**: Used by Tailwind to process your CSS.

## 🚀 How to Use This Project

### 1. Install Everything
Open a terminal in this folder and run:
```sh
npm install
```
This downloads all the tools and libraries you need.

### 2. Start the Website (Development Mode)
```sh
npm start
```
This launches the website locally. Open [http://localhost:3000](http://localhost:3000) in your browser to see it.

### 3. Build the Website (Production)
```sh
npm run build
```
Creates an optimized version of your site in the `build/` folder, ready to deploy.

### 4. Build Tailwind CSS
If you change Tailwind classes, rebuild your CSS:
```sh
npm run build:css
```
This updates the CSS in `dist/index.css`.

### 5. Serve the Production Build
To preview the production build locally:
```sh
npm install -g serve
serve -s build
```

## 🛠️ Customizing Your Website

- **Edit pages in `src/pages/`** to change content.
- **Edit components in `src/components/`** to update Navbar, Footer, Hero, etc.
- **Use Tailwind CSS classes** in your JSX for easy styling. Example: `className="bg-blue-500 text-white p-4"`

## ❓ Common Questions

- **What is React?**  
  A tool for building interactive websites using components.

- **What is Tailwind CSS?**  
  A tool for styling your site using utility classes (like `bg-blue-500` for a blue background).

- **What is a component?**  
  A reusable piece of your website (like a button, navbar, or footer).

- **What is a page?**  
  A main section of your website (like Home, About, Products, Team, Contact).
